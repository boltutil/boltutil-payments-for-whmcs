# BoltUtil Payments for WHMCS

Accept USDT and USDC for USD invoices through BoltUtil Hosted Checkout. The package includes the payment gateway, the payment records addon and installation instructions.

## Preview release

**0.1.0-preview** passed isolated PHP 8.2, PHP 8.3 and MySQL 8.4 checks. Compatibility with a licensed WHMCS installation has yet to be verified. Use a private test instance.

[Download the installation ZIP](https://github.com/boltutil/boltutil-payments-for-whmcs/releases/download/v0.1.0-preview/boltutil-whmcs-0.1.0-preview.zip)

The module is free under GPL-2.0-or-later. A configured BoltUtil merchant account is required. BoltUtil service fees and blockchain fees depend on your configuration and payment route.
